## Key design decisions ratified

- Two-layer rubric: 10 universal type-level rubrics (axes + weights
  fixed per type) + per-question concept overlay (concepts + weights +
  `relevant_axes` referencing the type's axes).
- Universal layer is cross-topic (never bootstrapped on a single course).
- Calibration criterion: concept-vote agreement (≥0.85) + score bands
  + axis discrimination (with axis-perturbation answers as a diagnostic).
- Discrete judge labels `{full=1.0, partial=0.5, none=0.0}`. Per-axis
  criteria written in the rubric. Judge picks a label, not a number.
- Every run in `runs/<id>/` (W&B-style isolation). Run id format
  `YYYY-MM-DD_HH-MM-SSZ__<fingerprint>` (correlates with `.specstory/history/`).
- Reproducibility: full `src_snapshot.tar.gz` + `git_sha` per run.
- Persistence policy: nothing inside a run folder is ever discarded.
- **Activity logging (16:14 addition):** every agent/subagent activity
  is logged with start + end times + name in
  `traces/<stage>/timeline.jsonl` (event types: stage, iteration,
  subagent_dispatch, python_helper_call, gate_decision, error).
  Three nested trace layers: aggregate summary → activity timeline →
  per-subagent JSON → session transcript.
