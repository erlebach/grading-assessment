## Symbols introduced

- `Level(str, Enum)` — judge-output level: `full`, `partial`, `none`. Distinct from `ScoreLevels` (rubric criteria container) — same string values, different role.
- `AnswerGrade` — per-answer record: id, per-concept-per-axis Level votes, aggregate ∈ [0,1], aggregate_x10 ∈ [0,10], optional `target_axis_drop_observed` for axis-perturbation answers.
- `GradesSummary` — per-question summary: mean_by_quality, ordering_preserved, bands_satisfied, axis_discrimination_passed.
- `Grades` — top-level artifact for `grades/<course>/<q>/grades.yaml`.
- `validate_grade(raw, *, rubric, universal)` — enforces:
  1. `question_id` parity with rubric.
  2. Per-answer (concept, axis) pair set equals the rubric's `concept_overlay × relevant_axes` cartesian set (raises on missing or extra).
  3. `aggregate_x10 ≈ aggregate * 10` within `WEIGHT_EPSILON`.
