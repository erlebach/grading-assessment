## Symbols introduced

- `RubricDiff` — frozen dataclass: `type_name`, `weight_deltas: dict[str, float]`, `axes_added: list[str]`, `axes_removed: list[str]`, `status_changed: tuple[str, str] | None`. `is_identical()` returns True only when all four diff fields are empty/None.
- `GradesDiff` — frozen dataclass: `question_path`, `aggregate_deltas: dict[str, float]`. `is_identical()` returns True when every delta is exactly 0.0.
- `RunDiff` — top-level frozen dataclass holding `universal_rubrics: dict[type, RubricDiff]` and `grades: dict["course/qid", GradesDiff]`, with a recursive `is_identical()`.
- `_load_yaml`, `_diff_universal`, `_diff_grades` — private helpers.
- `diff_runs(run_a, run_b)` — entry point. Walks `<run>/types/<TYPE>/universal_rubric.yaml` and `<run>/grades/<course>/<qid>/grades.yaml`, returning `RunDiff`.

## Notes

Scope is intentionally limited to universal rubrics and grades for this foundation step; per-question rubrics, sources, seed questions, and synthetic answers are *not* yet diffed (the module docstring flags this — the per-stage plans will extend it). Floating-point tolerance is `round(delta, 9)`; identical-delta filtering uses an exact `== 0.0` comparison after that rounding, which is safe at 9-decimal precision.
