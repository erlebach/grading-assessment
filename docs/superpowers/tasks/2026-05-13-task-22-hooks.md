## Notes

The hook is intentionally a stub: it re-validates the most-recent run, not the **active** run. The per-stage plan that introduces an active-run pointer file (e.g. `preprocessing/runs/.active`) will rewire the script to read that pointer instead. Until then, the hook still gives a useful canary for any subagent that mutates the most-recent run incorrectly.
