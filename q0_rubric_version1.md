Single consolidated grading rubric (10 points total)

1. Object: definition, role, and table mapping (4 points)

* Full credit (4): Precisely defines an object as the observational unit / entity / case being analyzed, and explicitly maps it to a single row/record in the data table (i.e., one instance whose values are recorded across attributes).
* Partial (2–3): Correct general idea (unit of analysis/entity) but row/record mapping is missing, vague, or slightly confused (e.g., implies both rows and columns).
* Minimal (0–1): Definition is materially incorrect (e.g., calls an object a column/variable) or too ambiguous to assess.

2. Attribute: definition, role, and table mapping (4 points)

* Full credit (4): Precisely defines an attribute as a named descriptive property / variable / feature used to characterize objects, and explicitly maps it to a single column/field in the data table (values vary across rows).
* Partial (2–3): Correct general idea (property/variable/feature) but column/field mapping is missing, vague, or slightly confused.
* Minimal (0–1): Definition is materially incorrect (e.g., calls an attribute a row/object) or too ambiguous to assess.

3. Alternative names in data-mining practice (2 points total)
   Award credit only for correct, standard terminology, clearly associated with the correct concept.

* Object synonyms (1 point): Provides two acceptable alternative names for “object.” Examples include instance, sample, record, observation, data point, case, tuple.
  Scoring: 1 point if two correct synonyms are given; 0.5 if only one correct synonym; 0 if none or if misassigned (e.g., “feature” as an object synonym).
* Attribute synonyms (1 point): Provides two acceptable alternative names for “attribute.” Examples include feature, variable, field, dimension, predictor, input (or input variable).
  Scoring: 1 point if two correct synonyms are given; 0.5 if only one correct synonym; 0 if none or if misassigned (e.g., “record” as an attribute synonym).

General scoring notes (applies across all criteria)

* Precision matters: responses should clearly separate “unit being described” (object) from “property used to describe” (attribute).
* A student may use “row/record/tuple” language for object and “column/field” language for attribute; that is acceptable if the conceptual distinction remains correct.
* Do not double-count: synonyms should not substitute for the required definitions/mappings in criteria 1–2; they are scored only in criterion 3.
